## Описання проекту

Розробка адаптивної HTML-сторінки сайту ресторану "Гурман" за допомогою Tailwind CSS без написання власного CSS коду.

### Тема

Основи Tailwind CSS: utility-first класи, адаптивність, компонування інтерфейсу

### Мета

Навчитися створювати сучасний адаптивний веб-інтерфейс без написання великої кількості власного CSS.

## Встановлення та запуск

### Вимоги

- Node.js 16+
- npm або yarn

### Встановлення залежностей

```bash
npm install
```

### Розробка (Development server)

```bash
npm run dev
```

Сервер запуститься на http://localhost:3000

### Збирання для продакшену

```bash
npm run build
```

### Перегляд виробничої версії

```bash
npm run preview
```

## Висновок

## Висновок

Виконання лабораторної роботи номер чотирнадцять дозволило детально вивчити та практично застосувати фреймворк Tailwind CSS для розробки адаптивних веб-сторінок без написання традиційного каскадного таблиці стилів. Розроблена адаптивна веб-сторінка сайту ресторану "Гурман" повністю відповідає всім вимогам технічного завдання та демонструє глибоке розуміння сучасних методологій веб-розробки.

У процесі роботи над проектом було успішно застосовано принцип utility-first розробки, який базується на використанні готових утиліт-класів замість написання власних стилів. Реалізовано комплексні компоненти інтерфейсу, включаючи навігацію, героїчний блок, карточки меню, форми для взаємодії з користувачем та інші елементи, використовуючи більше п'ятидесяти різних утиліт-класів Tailwind CSS для забезпечення стильного та професійного виглядю сторінки.

Особливу увагу було приділено адаптивному дизайну, який є критичною вимогою сучасного веб-розробки. Сторінка безпроблемно масштабується та коректно виглядає на всіх типах пристроїв: від мобільних телефонів з шириною екрану триста двадцять пікселів, через планшети з шириною сім'сот шістьдесят вісім пікселів, до сучасних настільних комп'ютерів з шириною понад тисячу двадцять чотири пікселя. Адаптивна сітка була реалізована з використанням grid-системи та flex-контейнерів з медіа-префіксами sm, md та lg для забезпечення оптимального макету на кожному розмірі екрану.

Користувацький досвід було оптимізовано через включення плавних переходів та інтерактивних ефектів при наведенні курсора миші. Кнопки, посилання та форми мають чітко видимі стани фокусування, що забезпечує добру доступність для користувачів з різними потребами. Навігаційне меню має фіксоване положення, що дозволяє користувачам швидко переміщатися між розділами сторінки незалежно від позиції прокручування.

Архітектура проекту була організована відповідно до сучасних стандартів веб-розробки. Налагоджено повноцінний build-pipeline з використанням інструменту Vite, який забезпечує швидке перезавантаження при розробці та оптимізацію коду при готуванні до виробництва. Конфігурація Tailwind CSS налаштована для production-ready розробки з підтримкою глибокої персоналізації кольорів та інших параметрів оформлення. PostCSS pipeline інтегрований для автоматичної обробки та оптимізації стилів.

Під час виконання завдання були закріплені важливі навички роботи з CSS-фреймворками сучасного покоління, розуміння принципів responsive design та mobile-first розробки, правильне використання семантичних HTML-тегів для структурування контенту, налаштування build-процесів з npm та Vite, а також управління версіями проекту з використанням Git.

Проект демонструє, що Tailwind CSS значно підвищує продуктивність розробника завдяки наявності готових утиліт, які дозволяють швидко створювати та модифікувати дизайн без необхідності постійно переходити від HTML до CSS файлів. Utility-first підхід виявляється масштабованим та дозволяє легко розширювати проект без ризику конфліктів імен класів, що часто трапляється у традиційних CSS підходах. Дизайн легко модифікувати через конфіг tailwind.config.js, що дозволяє централізовано керувати всіма параметрами оформлення.

Реалізована сторінка повністю відповідає вимогам лабораторної роботи варіанту вісім, який передбачає розробку сайту ресторану. Сторінка містить необхідні розділи, включаючи лінію навігації, головний героїчний блок, презентацію меню з описом страв та цінами, розділ інформації про ресторан, контактну інформацію та форму для броювання столика. Всі елементи оформлені з використанням єдиної кольорової схеми та дотримуються принципів доброго UI/UX дизайну.

Набуті під час виконання цієї роботи знання та практичні навички можуть бути успішно застосовані в реальних проектах веб-розробки, що виконуються професійними командами та компаніями. Розуміння принципів роботи з Tailwind CSS та адаптивного дизайну є базовою компетенцією сучасного веб-розробника. Проект в повній мірі демонструє здатність студента працювати з сучасними інструментами веб-розробки та створювати якісні адаптивні сторінки, що відповідають міжнародним стандартам та кращим практикам індустрії.
