# Лабораторна робота №5 (Варіант 4: «Готель — номерний фонд»)

Цей проєкт є кліент-серверним веб-додатком для управління номерним фондом готелю, розробленим у межах лабораторних робіт з дисципліни «Розробка кліент-серверних веб-додатків».

## Архітектура проєкту
* **Бекенд (Серверна частина):** ASP.NET Core Web API (.NET 8)
* **Фронтенд (Кліентська частина):** React + Vite

---

## Структура репозиторію
Проєкт розташований у папці `ReactApp-Lab5` та містить такі основні компоненти:
* `Controllers/`, `Models/` — логіка та моделі даних бекенду.
* `client/` — вихідний код кліентської частини на React.
* `Program.cs` — налаштування та конфігурація ASP.NET Core додатку.

---

Для успішного запуску проєкту вам знадобляться встановлені **.NET SDK 8.0+** та **Node.js**.
