## Інформація про роботу
- **ФІО студента:** Гаврилов О.В.
- **Варіант:** 8 (CRM для фотоссесій)
- **Дисципліна:** Веб-технології та дизайн

---

## Мета роботи

Навичність розробляти адміністративний інтерфейс для керування клієнтами та задачами, реалізувати CRUD-операції, захистити доступ за допомогою авторизації та розмежування ролей.

---

## Описание основних функцій

### 1. Авторизація та аутентифікація
- Реалізована система авторизації за допомогою **Laravel Breeze**
- Користувачі можуть реєструватися та входити в систему
- Захист маршрутів за допомогою middleware

### 2. Система ролей та доступів
- Використано пакет **laravel-permission** для управління ролями та дозволами
- **Адміністратор** - повний доступ до всіх функцій
- **Менеджер** (Фотограф) - доступ лише до своїх фотоссесій та клієнтів
- **Клієнт** (користувач) - можливість переглядати свої замовлення

### 3. Сутності системи

#### Клієнти (Clients)
- Ім'я
- Email (унікальний)
- Телефон
- Дата і час створення

#### Фотоссесії (PhotoSessions)
- Назва
- Опис
- Дата проведення
- Тривалість
- Тип (весільна, сімейна, портретна, інші)
- Статус (нові, в процесі, завершено)
- Підв'язаний клієнт (FK з каскадним видаленням)
- Підв'язаний фотограф/менеджер (FK з каскадним видаленням)
- Дата і час створення

#### Користувачі (Users)
- Ім'я
- Email (унікальний)
- Пароль
- Роль (адміністратор або менеджер)
- Дата реєстрації

### 4. CRUD операції

**Для адміністратора:**
- ✅ Перегляд усіх клієнтів
- ✅ Додавання нових клієнтів
- ✅ Редагування інформації про клієнтів
- ✅ Видалення клієнтів
- ✅ Перегляд усіх фотоссесій
- ✅ Додавання нових фотоссесій
- ✅ Редагування фотоссесій
- ✅ Видалення фотоссесій
- ✅ Призначення фотографа на фотоссесію
- ✅ Управління користувачами (додавання менеджерів)

**Для менеджера (фотографа):**
- ✅ Перегляд списку своїх клієнтів
- ✅ Перегляд своїх фотоссесій
- ✅ Редагування статусу своїх фотоссесій
- ✅ Не може видаляти або редагувати фотоссесії інших

### 5. Middleware для перевірки ролей
- **RoleMiddleware** - перевіряє, чи має користувач потрібну роль
- Захист маршрутів для адміністратора та менеджера
- Повернення помилки 403 при спробі несанкціонованого доступу

### 6. Адміністративна панель
- Інтуїтивний дизайн на основі **Bootstrap 5**
- Навігаційне меню з посиланнями на основні розділи
- Швидкі статистики (кількість клієнтів, фотоссесій, користувачів)
- Таблиці з можливістю редагування та видалення записів
- Форми для додавання та редагування даних
- Модальні вікна для підтвердження видалення

### 7. Інтерактивність
- Використано **Alpine.js** для динамічних взаємодій
- Показ/приховування елементів без перезавантаження сторінки
- Валідація форм на клієнтській стороні
- Повідомлення про успіх/помилку операцій

## Розгортання та встановлення

### Крок 1: Створення проекту Laravel
```bash
laravel new crm-panel
cd crm-panel
```

### Крок 2: Встановлення Breeze (для авторизації)
```bash
composer require laravel/breeze --dev
php artisan breeze:install
php artisan breeze:install --teams
npm install && npm run dev
php artisan migrate
```

### Крок 3: Встановлення laravel-permission
```bash
composer require spatie/laravel-permission
php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider"
php artisan migrate
```

### Крок 4: Створення моделей та міграцій
```bash
php artisan make:model Client -m
php artisan make:model PhotoSession -m
php artisan make:migration create_roles_table
```

### Крок 5: Створення контролерів
```bash
php artisan make:controller ClientController --resource
php artisan make:controller PhotoSessionController --resource
php artisan make:controller DashboardController
php artisan make:middleware RoleMiddleware
```

### Крок 6: Запуск міграцій та сівачів
```bash
php artisan migrate
php artisan db:seed RoleSeeder
```

### Крок 7: Запуск розробницького сервера
```bash
php artisan serve
npm run dev
```
