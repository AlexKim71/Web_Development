## 🎯 Робочий процес розробника

### День 1: Встановлення
1. Прочитайте **QUICK_START.md** (5 хв)
2. Запустіть **install.bat** (5-10 хв)
3. Запустіть сервер та Vite (2 хв)
4. Увійдіть на http://localhost:8000 (1 хв)

### День 2-N: Розробка
1. Запустіть `php artisan serve` (в термінал 1)
2. Запустіть `npm run dev` (в термінал 2)
3. Редагуйте код в IDE
4. Змінни автоматично перезавантажуються

## 💡 Поради

### Для швидкого старту:
1. Просто скопіюйте і пасту команди з QUICK_START.md
2. Не пропускайте крок з `php artisan migrate`
3. Переконайтесь, що два термінали запущено одночасно

### Для розробки:
1. Використовуйте VS Code або PHPStorm
2. Встановіть розширення для Laravel
3. Почніть з редагування шаблонів в `resources/views/`

### Для вирішення проблем:
1. Прочитайте розділ "❌ Вирішення проблем" в INSTALL.md
2. Перевірте, що PHP, Node, Composer встановлені
3. Видаліть `node_modules` та переінсталюйте

## 👥 Структура проекту

### Для адміністратора CRM:
- Перейди на **http://localhost:8000/dashboard**
- Видиш всіх клієнтів та фотоссесій
